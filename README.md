# W2C 0.43.0 简体中文补丁

r2 修订版：剧情、选项、界面与教程汉化，补齐动态通知、活动状态等遗漏，附部分原版问题修复。

[下载补丁 ZIP](https://github.com/QianLieXian/W2C-0.43.0-chinese/archive/refs/heads/w2c-0.43.0-zh.zip)

## 安卓

1. 将原版 `W2C-0.43.0-android.apk` 放进此文件夹。
2. 在 Windows 双击 `安卓一键汉化.bat`，也可把 APK 拖到 BAT 上。
3. 安装 `output/W2C-0.43.0-zh-android.apk`。

首次运行会下载 Java 和签名工具。原包不会被修改。汉化版使用不同签名，安装前先备份存档，无法直接覆盖原版时需先卸载原版。

## 电脑

将 `payload/game` 合并到游戏的 `game` 文件夹，覆盖同名文件。启动后默认使用简体中文，也可在语言菜单中切换。

仅适用于 0.43.0。补丁不包含原版游戏。翻译采用 GPT 逐条语境翻译并统一术语；人名、作者名和链接保留原样。检查结果见 `校验说明.md`。
